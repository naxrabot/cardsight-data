# cardsight-data

Daily data for the CardSight app: every Pokémon card in English, Japanese and Chinese (Traditional/Simplified),
with rarity, variants and prices (TCGplayer USD, Cardmarket EUR) from [TCGdex](https://tcgdex.dev),
plus picture fingerprints used to recognise cards by their art.

Built every day by GitHub Actions and published to the [`latest` release](../../releases/tag/latest).
